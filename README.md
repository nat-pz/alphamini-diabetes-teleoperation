# Alpha Mini Diabetes Teleoperation

Python teleoperation system for the Alpha Mini robot with conversational AI for childhood diabetes education. The robot interacts with children through voice and text, simulating hypoglycemia, hyperglycemia, and normal glucose states in response to real-time data from a blood glucose simulator.

Developed as a Master's thesis project at the Universitat Politècnica de València (UPV).

---

## Features

- **Voice and text chat**: interact with the robot via microphone or keyboard; responses generated by Google Gemini and played back as audio
- **Glucose state simulation**: robot reacts to hypoglycemia, hyperglycemia, and normal glucose levels with actions, facial expressions, and spoken responses
- **Real-time simulator integration**: connects to a web-based blood glucose simulator via HTTP; accepts commands for insulin, carbohydrate intake, and exercise
- **Robot control**: walk, greet, perform actions and facial expressions using the Alpha Mini SDK
- **Bilingual**: Spanish and English support via Vosk offline speech recognition
- **Local audio server**: HTTP server for audio file delivery to the robot

## Requirements

- Alpha Mini robot, powered on and connected to the same Wi-Fi network as the host machine
- Microphone connected to the host machine
- Python 3.13 or compatible
- Google Gemini API key
- Vosk speech recognition model files (Spanish and/or English)

## Installation

**1. Clone the repository**

```bash
git clone https://github.com/nat-pz/alphamini-diabetes-teleoperation.git
cd alphamini-diabetes-teleoperation
```

**2. Install dependencies**

```bash
pip install -r requirements.txt
```

**3. Get a Google Gemini API key**

Go to [https://aistudio.google.com/apikey](https://aistudio.google.com/apikey), create a key, and add it to `keys.env`:

```
GOOGLE_API_KEY=your_key_here
```

**4. Download Vosk models**

Go to [https://alphacephei.com/vosk/models](https://alphacephei.com/vosk/models), download the Spanish and/or English model, extract the folders, and place them in the project directory. Make sure the folder names match the paths defined in `MainAlphaMini.py`.

**5. Set the robot ID**

Open `MainAlphaMini.py` and make sure the robot ID variable matches your Alpha Mini's ID.

**6. Run**

```bash
python MainAlphaMini.py
```

On startup, choose a language: `es` for Spanish, `en` for English. The application will search for the robot on the local network.

## Usage

Once connected, type a command and press Enter. Type `ayuda` / `help` at any time to list available commands.

| Command | Description |
|---------|-------------|
| `texto` | Text chat — type messages, robot responds aloud |
| `voz` | Voice chat — speak via microphone, robot responds aloud |
| `caminar [x]` | Walk x steps |
| `saludo [1-4]` | Execute greeting type 1–4 |
| `accion [x]` | Execute pre-programmed action x from the Alpha Mini SDK |
| `expresion [x]` | Execute pre-programmed facial expression x |
| `hipo` | Simulate hypoglycemia state |
| `hiper` | Simulate hyperglycemia state |
| `normal` | Simulate normal glucose state |
| `deporte` | Simulate exercise |
| `simular` | Start simulator mode (connects to web glucose simulator) |
| `salirsim` | Exit simulator mode |
| `salir` | Close the application |

### Simulator mode commands

While in simulator mode, use `v` (voice) or `t` (text) input with the following format:

```
comer 20                          # carbohydrate intake in grams
inyectar 5                        # insulin bolus in units
ejercicio suave/medio/fuerte 30   # exercise intensity and duration in minutes
```

## Web Simulator Setup

The web simulator runs as a Django application:

```bash
cd simulator/
pip install -r requirements.txt
python manage.py runserver
```

The server starts at `localhost:8000` by default. Once running:

1. Start the robot application and select simulator mode
2. Copy the IP shown in the console
3. Enter it in the "Robot" field on the web interface and click "Conectar"
4. Start the simulation from the web interface

The simulator can then be controlled from both the web interface and the robot application simultaneously.

The web simulator code is not available to the general public.

## Troubleshooting

**Robot does not connect**
- Make sure the robot and host machine are on the same Wi-Fi network
- Check that the robot ID in `MainAlphaMini.py` is correct

**Voice recognition does not work**
- Check that the microphone is working
- Verify that the Vosk model folders are in the project directory and that the paths in `MainAlphaMini.py` are correct

**Audio server does not start**
- Port 8080 may be in use by another application — check for port conflicts

**Robot does not play audio**
- Check that the local HTTP server is running and that the robot can reach the host machine's IP

**AttributeError: 'ClientConnection' object has no attribute 'closed'**

This is a bug in the Alpha Mini SDK. Open `websocket_client.py` from the Alpha Mini library and change:

```python
return self._client and (not self._client.closed)
```

to:

```python
return self._client
```
